# Running RigMark for someone

- Run `./rigmark check` before benchmarking. It checks the newest published
  release, including pre-releases. If this checkout is behind, update it first.
  If GitHub is unreachable, say that the release status was unverified.
- Run the standard suite unless asked for different settings. Disclose every
  changed flag and request body; do not call unlike receipts a matched result.
- Use real appliance metadata. Never guess the model revision, quantisation,
  engine, drafter, topology, or competing traffic.
- After a run, give the person the **full generated ASCII** from the `.card.txt`
  path printed by RigMark as a `text` code block or an attached file. Also link
  or attach the matching `.json` receipt. A summary table alone is
  insufficient. Do not omit prefill, settings, appliance, or source details.
- If sharing publicly, check metadata and retained model output for private
  information before publishing the JSON.
